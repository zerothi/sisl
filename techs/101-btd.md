# 101 · BTD

Owns: `src/sisl_toolbox/btd/*`

Paths are relative to `src/sisl_toolbox/btd/`.

`btd` calculates quantities that TBtrans does not give:
spectral functions, scattering states, scattering matrices and eigenchannels.
It uses the block-tridiagonal (BTD) structure of the device Hamiltonian.

## Modules

| Module | Content |
|---|---|
| `_green.py` | `DeviceGreen`: the device Green function and the main API. |
| `_electrode.py` | `Electrode` classes: self-energies. |
| `_btd.py` | `PermuteBTD`, partitioning, `BlockArray`. |
| `permute/` | Cython graph algorithms for bandwidth reduction and blocks. |
| `_help.py` | Spin expansion of orbitals and blocks. |

## DeviceGreen

`DeviceGreen(H, elecs, permute=...)`:

- An electrode is `(elec, idx[, bulk])`, or an `Electrode` with `.orbs` set.
- `idx` is atoms by default. Use `{"atoms": idx}` or `{"orbitals": idx}` to be explicit.
- Electrode names are unique. The comparison ignores letter case.
- On a copy of `H`, the couplings along the semi-infinite directions of the electrodes are removed.
- The main methods: `green`, `spectral`, `scattering_state`, `transmission`, `scattering_matrix`, `eigenchannel`.

### `permute`

`permute` accepts:

- a `PermuteBTD`;
- an index array. The blocks are then calculated;
- a method string `[atom+|orb+]<method>`.
  `electrode=<name|index>` starts the order at that electrode (default: the first).

The electrode orbitals go to the partitioner as dense blocks.
An atom partition is expanded to orbitals, then to spin.

`_elec_index` finds an electrode from an index, a name (letter case ignored) or an object.
It also follows `DownfoldElectrode.electrode` chains.

### Constructors

- `from_tbt`: uses the regions from TBT.nc (`pivot`, `btd`, `pivot_down`, `a_elec`, `mu`, `eta`, `bloch`).
  TBT.nc does not store the electrode Hamiltonians or the semi-infinite directions.
  Thus the user gives them by name.
- `from_fdf`: reads the fdf and its Hamiltonian files. It calculates the regions again.
  The pivot method is from `TS.BTD.Pivot`, `TBT.BTD.Pivot` or `TBT.BTD.Pivot.Device` (default `atom+GPS`).
  A method that btd does not support changes to GPS with a warning.

## Electrodes

`Electrode` is an abstract base class. It has a keyword-only `name`, `orbs` and `info`.
A subclass implements `__len__`, `self_energy` and `se2broadening`.

| Class | Use |
|---|---|
| `BlochElectrode` | A self-energy with a Bloch expansion. |
| `RealSpaceElectrode` | Many semi-infinite directions (`RealSpaceSE`, `RealSpaceSI` or a GF file). |
| `DownfoldElectrode(electrode, H, elec, down)` | Downfolds an electrode into the last block. It can wrap another `DownfoldElectrode`. It does not know the device region. |

- `Electrode.from_fdf` returns the class that matches the fdf electrode block.
- GF files are read through `_GFSelfEnergy`.
- These classes replace `PivotSelfEnergy` and `DownfoldSelfEnergy` (`changes/toolbox/1024.change.rst`).

## Partitioning

- `PermuteBTD(permute, blocks)` is a dataclass. `perm[new] = old`.
  `blocks` is block sizes, or a list of index arrays for each block.
- `btd_partition`: bandwidth reduction, then `btd_blocks` with a cost model,
  then sorts the indices in each block for memory access.
- A dense block spans at most 2 adjacent blocks.
- The method `electrode` accepts at most 2 dense blocks. They become the first and the last block.
- `btd_partition` and `downfold_partition` work on matrix rows.
  To partition atoms, give `H.toSparseAtom()`.

### BlockArray

`BlockArray` is an N-d `ndarray` subclass that holds blocks. `None` is a structural zero.
ufuncs and matmul use only the defined blocks. Other operations make the array dense.
It replaces `BlockMatrix`.

## `permute` subpackage

`permute/_permute.pyx` holds the graph algorithms:
`symmetric_graph`, Cuthill-McKee, GPS, generalized GPS, `electrode_ordering`, `refine_bandwidth`, `btd_blocks`.

- All algorithms use a symmetric CSR graph without self-loops.
- `btd_blocks` uses dynamic programming for the cost `speed-diagonal`.
  It uses branch-and-bound for `speed` and `memory`.
- Index arrays use the fused type `int_sp_st` from `sisl/_core/_dtypes.pxd`.
  The output has the index dtype of the input (`int32` or `int64`).
- `permute/__init__.py` accepts a `SparseCSR` or a scipy sparse matrix. It requires `ncol % nrow == 0`.
  `csr_graph` folds the supercell columns with `fold_csr_array`. Then it makes the graph symmetric.
- `reduce_bandwidth` methods: `[rev-]{cm,rcm,gps,ggps,electrode}`. The refinement does not move electrode nodes.

## Build

- The root `CMakeLists.txt` adds `src/sisl_toolbox/btd/permute` as a subdirectory.
- `add_cython_library` adds `-I <project>/src`. Thus `cimport sisl._core...` works from outside `sisl`.
- A stale installed `sisl` can supply an old `.pxd`. See [10 · Stale Cython builds](10-build.md#stale-cython-builds).
