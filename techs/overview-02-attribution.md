# overview-02 · Attribution

This file lists the outside material that inspired the rules and the workflow in `techs/`.
It is not the list of the sources of a physics method. Those are in `docs/references.bib`.

## Rules for this file

- Add an entry when an idea, rule or text in `techs/`, `AGENTS.md` or a tool comes from outside material.
  Outside material is, for example, an article, a book, an agent skill or a style guide.
- Add the entry in the same commit as the content.
- Do not remove an entry while the content that it inspired stays.
- Keep the copyright line and the license text if the license requires them, for example MIT.
- Give each entry: the title, the author, the date, the link, the license and the chapters that use it.
